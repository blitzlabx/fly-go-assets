# Fly Go Assets

Official asset repository for **Fly Go** — characters, branding, data, and creative guidelines.

## Structure

```
fly-go-assets/
├── assets/
│   ├── branding/          # Logos, icons, wordmarks
│   ├── characters/        # Per-character art + metadata
│   ├── backgrounds/
│   ├── environments/
│   ├── animations/
│   ├── effects/
│   ├── audio/
│   └── ui/
├── data/                  # Core game/world JSON data
├── docs/                  # Universe, story, art direction
├── scripts/               # Validation utilities
└── .github/workflows/     # CI for asset validation
```
